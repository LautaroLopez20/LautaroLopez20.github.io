Ejercicio Entregable Nº2
Desarrollo de interfaz de usuario
Este práctico contempla utilizar HTML5, JavaScript y CSS3 (animaciones simples) para continuar el trabajo anterior e Implementarlo. 
Para esto, se debe maquetar y diseñar en Alta las mismas páginas que las mencionadas en el trabajo anterior.
Obviamente, no tiene que estar resuelto el backend del sitio, sino sólo estar diagramado lo que se necesite para la presentación del flujo que se muestra. NO se recomienda utilizar ningún framework de JS: (Angular, React, Vue, etc.) ni de CSS (Bootstrap, etc.) dado que puede complicar el práctico con problemas muy específicos.
Realizar la maqueta utilizando las tecnologías y los lenguajes ya mencionados (HTML5, JS, CSS3). 

El usuario debe poder interactuar con las 3 páginas descritas en el práctico anterior. Por ejemplo:
El usuario debe poder interactuar con la Home de Inicio, por ejemplo revisar los juegos destacados, abrir una página de ejecución del juego (Peg Solitaire), etc. 
Login/Registro: Aplicar animaciones en caso de registro correcto
Deben incluir animaciones Hover en botones.
Al menos 3 diferentes.
Al cargar la Home se debe ejecutar siempre un loading simulado de 5 segundos, el cual NO puede ser un GIF. El mismo debe mostrar un % de avance y una animación de carga (cuadrado, círculo, spinner)
Contener al menos una galería/carrusel de imágenes animada. Es decir que la transición entre imágenes de la galería están animadas. Puede ser por ejemplo en la página de descripción de un juego.
No es solo que se mueva, tiene que tener transiciones de animación. 
Los datos que se muestran que no sean genéricos, ni tampoco Loren Ipsum. 
Si muestran más de un juego deben tener imágenes diferentes.
Los títulos de los juegos que sean reales.
Utilizar títulos de juegos de diferente longitud, para ver como se ven con títulos cortos y largos.
Poner imágenes de diferentes colores y variedades para identificar cómo se acomoda el diseño a las diferentes opciones.
Plus: Utilizar la API propuesta por la cátedra para tomar datos y utilizarlos en el sitio. Info API: https://github.com/jimartinezabadias/api-vj-interfaces

Diseño Mobile First: Se debe desarrollar	 el Home del sitio para las versiones mobile y desktop. (Aclaración: el resto de las páginas deberán ser desktop.)
